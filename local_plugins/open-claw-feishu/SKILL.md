# Open Claw Feishu (Local)

Use local scripts in this repository:

- `feishu_long_connection_client.py`: start Feishu official long-connection mode.
- `setup_feishu_mode.sh --local-only`: store app credentials and install local skills without network checks.
- `open_claw_feishu_adapter.py`: receive Open Claw events and forward to Feishu APIs/webhook.
